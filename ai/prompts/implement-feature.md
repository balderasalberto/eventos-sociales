# Implementar funcionalidad

## Contexto

Actúa como agente de desarrollo dentro de este repositorio.

## Entrada

- Requisito: `<RF-XXX>`
- Objetivo: `<descripción>`

## Instrucciones

1. Lee `SPEC.md` y la documentación relacionada.
2. Identifica los criterios de aceptación.
3. Revisa el código y los tests existentes.
4. Propón un plan breve antes de modificar archivos.
5. Crea o actualiza las pruebas necesarias.
6. Implementa el comportamiento.
7. Ejecuta las validaciones disponibles.
8. Revisa el diff.
9. Resume archivos modificados, tests ejecutados y cualquier decisión pendiente.

## Restricciones

- No inventar requisitos.
- No introducir dependencias innecesarias.
- No modificar funcionalidades no relacionadas.
- No incluir secretos.
- No asumir un lenguaje o framework que no exista en el proyecto.
