# Crear pruebas

## Entrada

- Requisito: `<RF-XXX>`
- Criterio de aceptación: `<criterio>`

## Instrucciones

1. Identifica el comportamiento que debe verificarse.
2. Revisa tests existentes para evitar duplicación.
3. Define casos felices, límites y errores relevantes.
4. Escribe las pruebas usando el framework que corresponda al proyecto.
5. Ejecuta las pruebas.
6. Reporta qué comportamiento quedó cubierto.

## Regla

Las pruebas deben describir comportamiento esperado y no forzar una implementación determinada.
