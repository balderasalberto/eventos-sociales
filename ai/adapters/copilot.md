# Adaptador para GitHub Copilot

Este archivo contiene solamente instrucciones de adaptación para GitHub Copilot.

## Regla

Las reglas de negocio y de ingeniería permanecen en `SPEC.md`, `docs/` y `ai/instructions/`.

Cuando GitHub Copilot utilice instrucciones específicas del repositorio, estas deben mantenerse alineadas con las reglas neutrales y no duplicar decisiones de negocio.

## Uso

Consultar el prompt o flujo correspondiente en `ai/prompts/` y las reglas de `ai/instructions/`.

No agregar aquí reglas específicas del producto.
