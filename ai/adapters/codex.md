# Adaptador para Codex

Este archivo contiene solamente instrucciones de adaptación para Codex.

## Regla

Las reglas de negocio y de ingeniería permanecen en `SPEC.md`, `docs/` y `ai/instructions/`.

`AGENTS.md` puede utilizarse como punto de entrada de instrucciones del repositorio cuando la herramienta lo soporte.

## Uso

Antes de una tarea, cargar o consultar:

1. `AGENTS.md`
2. `SPEC.md`
3. documentación relacionada
4. `ai/instructions/`
5. el prompt correspondiente en `ai/prompts/`

No agregar aquí reglas específicas del producto.
